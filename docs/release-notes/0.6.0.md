**Saidright 0.6.0** · Apple silicon · macOS 14 or later · free and open source (Apache 2.0)

Not notarized by Apple. On first launch open **System Settings → Privacy & Security → Open Anyway**. The DMG's SHA-256 is attached as `Saidright.dmg.sha256`.

### New name
Saywell is now **Saidright**. Coming from Saywell? Quit it, then open Saidright: your modes, history, practice cards and downloaded models move over automatically, and a saved API key is carried over the first time it is used (macOS may ask once to allow Keychain access). macOS asks for Microphone, Input Monitoring and Accessibility again because the app's identity changed.

### Smart formatting
Dictate a few tasks and get a checklist; list things and get bullets; describe steps and get a numbered list. Ordinary sentences stay as they are. Works in every mode that edits text and can be switched off per mode (Modes → Smart formatting). The result is Markdown, which Notion, Obsidian, Slack, GitHub, Bear and many editors display as formatting.

### Also
- Whisper is about twice as fast on short mixed-language phrases (identical transcripts).
- Polished settings text in all four languages; centred Practice empty state.

### Known limitations
Apple silicon only; most testing on the newest macOS. Small local text models format less reliably than larger ones; when a layout cannot be verified, Saidright keeps the plain edit. Full list: docs/TESTING.md.
