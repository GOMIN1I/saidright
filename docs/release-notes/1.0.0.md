**Saidright 1.0** · Apple silicon · macOS 14 or later · free and open source (Apache 2.0)

Not notarized by Apple. On first launch open **System Settings → Privacy & Security → Open Anyway**. The DMG's SHA-256 is attached as `Saidright.dmg.sha256`.

**Speak freely.** Stop fearing imperfect words — set your speech free.

### Tables by voice
Say “I need a table with three columns: ChatGPT, Claude and Gemini”, then the values. Smart formatting returns a Markdown table — for notes, documents and AI chats. Every cell comes from what you said; a greeting before the request stays.

### A living app
Windows sit on a slowly drifting aurora — voice blue, violet and rose over deep indigo at night, over airy mist by day. A ring of the same lights turns around the record button and brightens while you speak; the capsule breathes with a soft moving light. Prefer plain macOS colours? Settings → Appearance → Window colour → System. Reduce Motion stops every animation.

### Faster
- Long dictations: finished phrases are recognised while you are still speaking (real recordings: 3.1 s → 0.7 s after you stop).
- Short, already clean phrases in light modes no longer wait for the text model.
- Smart formatting is requested together with the edit (table requests ≈1.4 s → 0.9 s on Groq).
- Recommended fast, free text service: Groq with `openai/gpt-oss-120b` (Text & AI → Compatible server `https://api.groq.com/openai/v1`, “Answer without thinking” on) — about 2.3× faster than the previous default in our tests.

### First launch
A new person sees only the introduction, centred, with a short animated welcome; finishing it opens the main window.

### Fixes
- Settings search no longer gets stuck when nothing matches (Clear search, Esc).
- The main window has no empty band on top; close, minimise and zoom buttons are visible.
- Long app names no longer stretch the main window.

### Known limitations
Apple silicon only; most testing on the newest macOS. Small local text models format less reliably than larger ones; when a layout cannot be verified, Saidright keeps the plain edit. Free cloud tiers have daily limits. Full list: docs/TESTING.md.
