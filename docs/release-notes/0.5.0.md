**Saidright 0.5.0 — developer preview** · Apple silicon · macOS 14 or later · free and open source (Apache 2.0)

Not notarized by Apple. On first launch open **System Settings → Privacy & Security → Open Anyway**. The DMG's SHA-256 is attached as `Saidright.dmg.sha256`.

### Highlights
- Dictate in any app with right ⌘; text appears at the cursor, locally.
- Recognisers: Whisper large-v3-turbo, NVIDIA Parakeet TDT 0.6B v3 (≈0.1 s per phrase), Apple on-device; *Automatic* chooses per mode.
- Learning tips grow out of the capsule after the text is inserted: correction, friendly explanation, example; ⌃⌥L reopens the last one.
- Quiet voices and mixed Russian/English speech are handled much better (see eval/results).
- Settings with search, Appearance (Liquid Glass / Ink, palettes, motion), first-run introduction in four languages, new icon with automatic dark and tinted variants on macOS 26+.

### Downloads inside the app
The recogniser (0.5–2.5 GB) and its runtime (~0.6 GB) are downloaded only when you choose them, with checksums verified. Text editing and tips are optional: local through Ollama, or a cloud key you add.

### Known limitations
Apple silicon only; most testing on the newest macOS. Some apps report insertion as “not verifiable”. A clean-account install has been tested in an isolated folder, not yet on a separate macOS user. Full list: docs/TESTING.md.

### Since the preview builds
- Whisper is about twice as fast on short mixed-language phrases (one encoder pass shared by language detection and decoding; identical transcripts).
- Polished settings text in all four languages.
