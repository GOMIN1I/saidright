# Qwen3-ASR 0.6B vs Whisper large-v3-turbo — 2026-10-18

Apple M4 Pro, 24 GB, macOS 27.0. Question: can Qwen3-ASR 0.6B (Alibaba, Apache-2.0) replace Whisper turbo for short phrases and make recognition at least 2× faster without losing accuracy, above all in mixed Russian + English speech?

**Answer: no.** It is 4× faster, but it translates whole Russian sentences into English (or English into Russian when Russian is forced), drops the second language, writes English product names in Cyrillic, and makes more errors in plain Russian. Not integrated.

## Setup

- **Qwen3-ASR**: `mlx-community/Qwen3-ASR-0.6B-bf16` (1.6 GB) and `-8bit` (1.0 GB) through `mlx-qwen3-asr` 0.4.4 (MLX 0.32.4) in a scratch venv; downloaded with the owner's consent and deleted after the run. Whole file in, automatic language detection (`auto`) or one forced language (`Russian`). Qwen3-ASR accepts a single language per call; there is no "ru or en" restriction like the app's Whisper path.
- **Whisper**: large-v3-turbo fp16 through `Resources/recognizer.py`, exactly as the app runs it (VAD, per-region language ID restricted to ru+en, encoder cache).
- **Clips**: 41 synthetic (`eval/fixtures.json` + `eval/routing-fixtures.json`, macOS voices) and, read-only, the owner's 41 real recordings (0.8–241 s, 25 of them ≤ 6 s). Real recordings have no reference text: they are compared with Whisper's output, and their text stays outside the repository.
- Each engine in its own process, one warm-up clip, then every clip decoded once. (An earlier run repeated each clip and took the median; that is invalid for Whisper because the encoder cache returns the previous pass for identical audio — it showed 0.06 s.)
- Script: `scripts/compare-qwen3-asr.py`.

## What goes wrong

**Translation in mixed speech (auto).** Qwen picks one language for the whole utterance (its output starts with `language X<asr_text>`) and transcribes everything into it. On the 7 mixed synthetic clips:

| clip (spoken) | Whisper | Qwen 0.6B, auto |
| --- | --- | --- |
| mixed-1: «Я проверил логи.» + “And the deploy failed again.” | Я проверил логи. And the deploy failed again. | **I verified the logs**, and the deploy failed again. |
| mixed-2: «Напиши клиенту.» + “We will send the invoice…” | Напиши клиенту. We will send the invoice tomorrow morning. | *(Russian sentence dropped)* We will send the invoice tomorrow morning. |
| mixed-6: «Встреча переносится.» + “Let me know if Thursday…” | Встреча переносится. Let me know if Thursday works for you. | **The meeting is postponed.** Let me know if Thursday works for you. |
| mixed-5: “I need to finish the report first.” + «Давай созвонимся…» | I need to finish the report. Давай созвонимся после обеда. | **Я** need to finish the report first. Давай **звонимся** после обеда. |

**Translation the other way (forced Russian).** Forcing Russian keeps the Russian sentences but translates English ones in the owner's real recordings: “My favorite food – pizza” → «мой любимый блюдо пицца», a nine-word English question → «что ты думаешь о …», short English replies become «вот»/«да»; 11 of 41 recordings change script. It also hallucinates text on silence and noise (2/2) and turns German/Chinese into Russian.

**English terms in Cyrillic.** In Russian dictations Qwen writes GitHub → «гитхаб», Telegram → «телеграм», Anthropic → «антропик», “Sonnet 5.5” → «сонет пять точка пять», Figma → «фигму», and garbles inline terms (“README” → «Эдмиот»), where Whisper keeps the Latin spelling.

**Plain Russian is worse.** Errors Whisper does not make: «с Анной» → «Саанной», «когда освободишься» → «когда я свободишься», «напомни» → «напомним», «в пятницу» → «в пять нити».

**Other.** One real English phrase came out in Chinese in the bf16 auto run. Learner grammar is kept (“Yesterday I go to the shop…”, “My mom are…”), so it does not “correct” errors — the one requirement it passes.

**Context prompt does not fix it.** A bilingual hint («Диктовка на русском и английском…») or a list of English terms as `context` changed only mixed-1 (Russian kept); mixed-2 still drops Russian and mixed-6 still translates.

## Recommendation

- **Do not integrate Qwen3-ASR 0.6B**, in mixed or single-language modes. In mixed modes it violates the app's core rule (never translate between the person's languages); in Russian it is clearly less accurate; in English-only it is 4× faster but triples WER (0.9 % → 2.8 %) — and Parakeet, already built in, is faster still (≈0.1 s) with similar single-language accuracy.
- **Qwen3-ASR 1.7B** was not tested. The single-language-per-utterance output format is the same, so translation of mixed speech is expected there too; not worth a ~3–4 GB download for this goal.
- The 2× goal is better served outside the recogniser: Whisper is ≈0.4 s of a ≈2 s short phrase, and the cloud editing step is 1.0–1.5 s (`2026-10-17-speed.md`). Even a 0 s recogniser would not halve the wait.

## Reproduce

```
G="$HOME/Library/Application Support/Govori"   # any Python with mlx-whisper + the turbo model
python3 -I scripts/compare-qwen3-asr.py \
  --whisper "$G/runtime/bin/python3:$G/models/whisper-turbo" \
  --qwen "<venv with mlx-qwen3-asr>/bin/python:<Qwen3-ASR-0.6B-bf16 dir>" \
  --qwen "<venv>/bin/python:<Qwen3-ASR-0.6B-8bit dir>" \
  --qwen "<venv>/bin/python:<Qwen3-ASR-0.6B-bf16 dir>:Russian" \
  --recordings "$HOME/Library/Application Support/Saidright/Recordings" \
  --dump <rows.json outside the repo> --out <report.md>
```
