<h1 align="center">Saywell</h1>

<p align="center"><b>Говори в любом приложении Mac — текст появляется там, где курсор.</b><br>
Локальное распознавание речи, режимы обработки текста и необязательные языковые подсказки, которые не мешают.</p>

## Что умеет

- **Диктовка где угодно.** Нажми правый ⌘ (или ⌃⌥Пробел), говори, нажми ещё раз. Есть режим «удерживать». Обычные сочетания вроде ⌘C запись не запускают; Esc отменяет.
- **Честная вставка.** Текст попадает только в поле, где ты печатал. Если фокус ушёл, ничего не вставляется, текст лежит в буфере обмена, и Saywell объясняет почему.
- **Локальное распознавание.** Whisper large-v3-turbo (лучше всего для смешанной речи и китайского) или NVIDIA Parakeet TDT 0.6B v3 (≈0,1 с на фразу, 25 европейских языков) — оба через MLX на твоём Mac; встроенная диктовка Apple как вариант без загрузки. *Автоматически* выбирает Parakeet для одноязычных режимов и Whisper для смешанной речи — см. [как устроено распознавание](docs/RECOGNITION.md). Числа пишутся цифрами.
- **Два языка сразу.** Режим «русский + английский» оставляет английские термины латиницей («посмотри мой pull request») и понимает переключение языка посреди диктовки.
- **Режимы.** Оставить как сказано, поправить пунктуацию, исправить грамматику или переписать в нужном тоне — для каждого режима свой уровень и предпросмотр изменений. Переключение ⌃⌥M.
- **Учись на своих фразах (по желанию).** После вставки текста из капсулы может появиться карточка с исправлением, дружелюбным объяснением на твоём языке и примером. Правильный текст ничего не получает. Подсказки можно сохранять для повторения. ⌃⌥L снова открывает последнюю.
- **Как родное приложение.** Капсула Liquid Glass или Ink, светлая и тёмная темы, настройки с поиском, уважение к «Уменьшению движения» и VoiceOver.
- **Приватно по умолчанию.** Аудио не покидает Mac. Правка и подсказки идут через модель, которую ты выбираешь: бесплатно и локально через [Ollama](https://ollama.com) или по своему облачному ключу; «Только локально» блокирует любые облачные запросы. Без аккаунта и телеметрии.

## Требования

| | |
| --- | --- |
| Mac | Apple silicon (M1 и новее); для Whisper turbo вместе с локальной текстовой моделью рекомендуется 16 ГБ памяти (при памяти меньше 12 ГБ Saywell предложит Whisper small) |
| macOS | 14 и новее (Liquid Glass и встроенная диктовка Apple — с macOS 26) |
| Диск | около 3 ГБ для Whisper turbo со средой выполнения; Parakeet — ещё 2,5 ГБ; Whisper small — 0,5 ГБ |
| Сеть | только чтобы один раз скачать распознаватель (и для облачного текстового сервиса, если выберешь его) |
| Разрешения | Микрофон; Мониторинг ввода — для одиночной клавиши вроде правого ⌘; Универсальный доступ — чтобы вставлять текст в другие приложения |

## Установка

1. Скачай `Saywell.dmg` в [Releases](../../releases/latest) и перетащи Saywell в «Программы».
2. Открой один раз. macOS скажет, что не может проверить разработчика, — нажми **Готово**.
3. **Системные настройки → Конфиденциальность и безопасность** → прокрути вниз → *«Saywell заблокировано…»* → **Всё равно открыть** и подтверди. (Бесплатные сборки не нотаризованы: для этого нужна платная учётная запись Apple Developer.)
4. Пройди вводный экран: языки, загрузка распознавателя внутри приложения (с проверкой контрольной суммы) и три разрешения.

Чтобы проверить загрузку, положи `Saywell.dmg.sha256` из релиза рядом с DMG и выполни `shasum -a 256 -c Saywell.dmg.sha256`.

## Использование

| Действие | По умолчанию |
| --- | --- |
| Начать / закончить диктовку | правый ⌘ · ⌃⌥Пробел |
| Отменить | Esc |
| Следующий режим | ⌃⌥M |
| Показать / закрыть последнюю подсказку | ⌃⌥L |

Диктуй в любое текстовое поле. Капсула внизу экрана показывает запись, обработку и готовность; текст вставляется туда, где ты печатал. Окно Saywell из Dock — это история, карточки для повторения и настройки.

## Настройка

Всё в **Настройках** (⌘,), с поиском:

- **Режимы** — языки речи, распознаватель (*Автоматически*, Whisper, Parakeet, Apple), насколько менять текст, языковые подсказки, куда отправлять текст.
- **Клавиши** — клавиша или сочетание для диктовки, нажатие или удержание, переключение режимов.
- **Распознавание** — установка и удаление распознавателей, личный словарь для Whisper.
- **Текст и ИИ** — правка и подсказки через локальную модель Ollama или совместимый с OpenAI сервис; «Только локально».
- **Обучение, Оформление, Данные, Дополнительно** — подача подсказок, вид капсулы, хранение и экспорт истории, ссылки автоматизации, диагностика.

Данные лежат в `~/Library/Application Support/Saywell` (настройки, режимы, история, загруженные модели). Ключи — в связке ключей macOS.

## Точность и скорость

Замеры на M4 Pro. Живая речь — 100 клипов Google FLEURS; смешанная речь и термины внутри фраз — синтетические клипы ([eval/results](eval/results)).

| Распознаватель | Короткая фраза | Ошибки в словах RU / EN / DE (FLEURS) | Смешанная RU+EN | Английские термины в русской речи |
| --- | --- | --- | --- | --- |
| Whisper large-v3-turbo | ≈0,5 с | 4,1 / 3,6 / 4,4 % | 3,1–3,4 % | остаются латиницей |
| Parakeet TDT 0.6B v3 | ≈0,1 с | 6,1 / 4,3 / 5,6 % | теряет второй язык | пишутся «на слух» кириллицей |

У тебя голос и микрофон другие; синтетические клипы проверяют работу цепочки, а не живые акценты.

## Сборка из исходников

Нужен Xcode 26 или новее (Swift 6).

```
scripts/check.sh                 # всё, что проверяет CI: тесты, сборка, строки, скрипты, поиск секретов
scripts/build-app.sh             # → build/Saywell.app
open build/Saywell.app
```

`SAYWELL_SIGN_IDENTITY=- SAYWELL_BUILD_DIR=build/public scripts/build-app.sh` собирает копию с подписью ad hoc, чтобы поделиться. Pull request'ы, релизы и страница продукта автоматизированы через GitHub Actions — см. [docs/GITHUB.md](docs/GITHUB.md).

## Безопасность и приватность

Аудио обрабатывается на Mac, ключи хранятся в связке ключей, загрузки проверяются по контрольным суммам, ничего не собирается. Подробности и как сообщить об уязвимости: [SECURITY.md](SECURITY.md) и [docs/PRIVACY.md](docs/PRIVACY.md).

## Ограничения

- Только Apple silicon. Больше всего проверено на новейшей macOS; на 14–15 должно работать, но проверено меньше.
- Некоторые приложения (браузеры, Electron) не показывают содержимое поля, поэтому вставка отмечается как «вставлено, проверить нельзя».
- Secure Input (поля паролей, некоторые терминалы) скрывает клавиши от всех приложений; тогда Saywell копирует текст вместо вставки.
- Произношение, акцент и беглость не оцениваются — по расшифровке это невозможно.
